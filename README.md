# 🎵 BayaPlus - Music Streaming Platform

## 📝 Overview

BayaPlus is a full-featured music streaming platform that connects artists and fans. Artists can upload and manage their music releases, while fans can discover new music, create playlists, follow their favorite artists, and enjoy seamless streaming. The platform includes a robust admin panel for content moderation and user management.

## ✨ Features

### 🎨 User Features

#### For Everyone
- **User Authentication** - Sign up, login, email verification
- **Music Discovery** - Browse trending tracks, recent releases, and curated content
- **Audio Streaming** - High-quality music streaming with 30-second play tracking
- **Search** - Find artists, tracks, and releases
- **Responsive Design** - Works on desktop, tablet, and mobile devices

#### For Artists
- **Release Management** - Create, edit, and publish music releases
- **Track Upload** - Upload audio files (MP3, WAV, FLAC) with cover art
- **Analytics Dashboard** - Track plays, likes, and engagement metrics
- **Profile Management** - Manage artist profile, bio, and social links
- **Release Status** - Draft, pending review, published, or rejected

#### For Fans
- **Personalized Dashboard** - Curated recommendations based on listening habits
- **Playlist Creation** - Create and manage custom playlists
- **Library** - Save liked tracks and followed artists
- **Follow Artists** - Stay updated with new releases from favorite artists
- **Like Tracks** - Heart your favorite songs

### 👑 Admin Features
- **Content Moderation** - Review and approve/reject artist releases
- **User Management** - Activate/deactivate users, manage roles
- **Admin Requests** - Process user applications for admin access
- **Platform Analytics** - View platform statistics and user activity
- **Release Management** - View and manage all releases on the platform

## 🛠️ Technology Stack

### Backend
- **Django 6.0** - Web framework
- **SQLite/PostgreSQL** - Database
- **Django REST Framework** - API endpoints
- **Django AllAuth** - Authentication

### Frontend
- **HTML5 & CSS3** - Markup and styling
- **Tailwind CSS** - Utility-first CSS framework
- **JavaScript (Vanilla)** - Interactive features
- **FontAwesome** - Icons

### Media & Streaming
- **Audio Streaming** - Range request support for audio files
- **Django Media** - File upload and serving
- **Pillow** - Image processing for cover art

## 📋 Prerequisites

- Python 3.8 or higher
- pip (Python package manager)
- Virtual environment (recommended)
